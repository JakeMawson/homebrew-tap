# JakeMawson Homebrew Tap

## Launch Station

Install [Launch Station](https://launchstation.net), the notarized macOS app
for starting, managing, and understanding every local project:

```sh
brew install --cask JakeMawson/tap/launchstation
```

Your launcher catalog and session history are preserved across upgrades and
uninstall.

## QuotaWise

Install [QuotaWise](https://github.com/JakeMawson/quotawise), a notarized
macOS menu-bar app for local AI usage intelligence:

```sh
brew install JakeMawson/tap/quotawise
```

## Codex Task Manager beta

Install [Codex Task Manager](https://stacksimpl.web.app/codex-task-manager/),
a signed and notarized macOS menu-bar companion for your Codex chats:

```sh
brew install --cask JakeMawson/tap/codex-task-manager
```

Requires macOS 15 or later and supports Apple silicon and Intel. This is an early
beta; task-status behavior is still being refined. Keep Codex as the
source of truth for your tasks.
